# 示例 / Examples

这里放的是**怎么用**的示例文件。项目只内置针对本地测试页的配方（[`templates/`](../templates/)），不内置任何真实网站的配方。

| 文件 | 用途 | 用法 |
|---|---|---|
| [`batch.demo.json`](batch.demo.json) | 多账号批量：两个演示账号各搜一个关键词，每次间隔几秒，每账号每天最多 3 次，登录失效就跳过 | 先在另一个终端运行 `browser-recipewright demo-server`，再 `browser-recipewright batch examples/batch.demo.json` |
| [`accounts.csv`](accounts.csv) | 用表格写账号清单（`id, profile, 每账号参数…`），适合账号多的时候 | 见 [批量说明](../skills/browser-recipewright/references/batch.md) |
| [`patch.example.json`](patch.example.json) | 按步骤 id 打补丁：页面把帖子容器改名后，只替换 `collect-posts` 这一步的定位器 | `browser-recipewright patch demo/local-feed examples/patch.example.json` 先看 diff，确认后加 `--write` |

## 内置配方 / Bundled recipes

| 配方 | 说明 | 需要登录 |
|---|---|---|
| [`selfcheck/basic`](../templates/selfcheck/basic.json) | 在本地自检页上跑一遍所有核心浏览器操作，确认安装可用 | 否 |
| [`demo/local-feed`](../templates/demo/local-feed.json) | 离线演示站上搜索并读帖子，用来练习 snapshot / act / patch / batch | 否（演示站里点一下 Log in） |

```bash
browser-recipewright selfcheck    # 自检
browser-recipewright demo         # 离线演示
```

在真实网站上用的配方，请让 AI 在你本机探索后生成并保存到 `~/.browser-recipewright/templates/`。

---

Files here show *how to use* features (batch, account lists, patches). The repo only bundles recipes for its own local test pages; recipes for real websites are generated by your agent and saved on your machine.
